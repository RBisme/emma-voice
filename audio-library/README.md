\# ============================================================

\# TradesMagic Runtime Audio Library

\# ============================================================



Purpose



This directory contains all prerecorded runtime audio assets used by

TradesMagic.



Examples include:



• Transfer ring tones

• Hold music

• Office ambience

• Business greetings

• Future runtime sound effects



This library exists so runtime audio assets are managed independently

from runtime code.



\---------------------------------------------------------------



Directory Structure

&#x20;   prompts/



&#x20;   effects/



\---------------------------------------------------------------



Design Goals



• Centralized runtime audio assets

• Reusable by all personas

• Expandable

• No hardcoded audio files throughout the runtime
